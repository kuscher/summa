# Summa: notes for working on the code

A Soulver/Numi-class notepad calculator for Googlebooks (Googlebook OS = Android 17 desktop) and
Android 12+. Plain APK, Kotlin + Jetpack Compose, Material 3 Expressive (material3 1.5.0-alpha, pinned).

## Layout
- `engine/` — pure Kotlin (no `android.*`), tested with JUnit on the VM. `./summa test`.
  - `Num.kt` exact `Rational` + `Num` (exact or approximate). `Units.kt` dimensions and `UnitExpr`.
  - `UnitCatalog.kt` the unit table (CLDR-style exact factors). `Currencies.kt` currencies, `Rates`, a tiny `Json`.
  - `Lexer.kt` settings, token types, the phrase lexicon (`Lexicon.ci`/`cs` tries) and the raw `Scanner`.
  - `Tokenizer.kt` raw pieces → tokens: times, dates, fractions, scales, line refs, variables, places;
    unknown words become comment spans (gaps). Context rules in `accept()` stop short symbols
    (m, C, B…) and common words from being read as units/places.
  - `Parser.kt` Pratt parser → `Node` tree; `led` backtracks on failure so a prefix still parses.
  - `Evaluator.kt` semantics: unit arithmetic (larger unit wins, money × time = money, simplify),
    conversions, every percentage form, dates/times/zones, functions.
  - `Formatter.kt` answers. `Sheet.kt` lines, labels, assignments, `sum` blocks, tags, the
    "last valid expression" fallback (`candidates()`), money rounding for references.
  - `Places.kt` offline zones: abbreviations, aliases, US states, GeoNames cities (resource), IANA cities.
  - Tests: `CorpusTest` runs `src/test/resources/corpus.tsv` (fixed clock and rates; add cases there),
    `RobustnessTest` fuzz + 1,000-line timing.
- `app/` — Compose app, package `io.github.kuscher.summa`.
  - `data/` `Library` (sheets as text files + index.json, Auto Backup), `Prefs` (settings → `EngineSettings`), `RatesRepo`.
  - `ui/editor/` `Session` (text state, background evaluation, autosave), `SheetEditor` (text field with
    syntax colours via `OutputTransformation`, answer rail aligned with `TextLayoutResult`), `Toolbar`.
  - `ui/library/Sidebar.kt`, `ui/settings/SettingsScreen.kt`, `ui/MainActivity.kt` (layout, shortcuts).
  - `ui/theme/` `Schemes.kt` is generated by `tools/schemes.mjs`; fonts by `tools/fonts.py`; icons by
    `tools/icons.py` (Material Symbols subset → `ui/Sym.kt`); launcher icon by `tools/logo.py`.
- `DebugReceiver.kt` — adb hooks (DUMP-guarded): `./summa debug list|open|new|text|cursor|dump|shot|screen|pref`.

## Dev loop
- `./summa app` builds, installs and launches on the Googlebook (adb over VSCodeBook's Unix socket,
  never tcp:5037). `./summa shot NAME` = PNG of Summa's own window (PixelCopy; no other apps).
- The user works on the HP while I test: check `./summa idle` first; don't inject keys.
- Debug builds are signed with the release key (~/.config/summa), so they replace releases and keep sheets.
- Release: bump `versionName`/`versionCode`, add `docs/release-notes/X.md` + CHANGELOG, `tools/release.sh --publish`.
  Key: ~/.config/summa/keystore.jks + keystore.pass (alias summa, cert SHA-256 57:24:72:36:…:5E:6D:32),
  backed up to a private folder; the password belongs in the user's password manager.
- Never run emulators on the VM; CI (GitHub Actions) builds and runs the engine tests.

## Gotchas
- `BigDecimal.sqrt()`/`BigInteger.sqrt()` are API 33: don't use them (minSdk 31). `Num` has its own roots.
- In composables, no early `return@Box` from content lambdas (Compose start/end imbalance crash).
- Text needs a `Surface` above it for the right content colour in dark mode.
- The Google Sans fonts are renamed "Summa Sans/Mono" when subset (Google's trademark notes).
- Desktop mode (Googlebook OS) ignores `<layout>` default sizes and `ActivityOptions.setLaunchBounds`:
  new windows get the shell's standard size (AOSP `DesktopModeUtils.calculateInitialBounds`).
- Caption bar: `CaptionTracker` follows `getBoundingRects(captionBar)` through the decor's insets
  listener; reading `rootWindowInsets` during composition is stale after a resize. Buttons in the
  caption need `Modifier.systemGestureExclusion()` or the system treats clicks as window drags.
- `Modifier.dragAndDropSource` caches its content's drawing: key the node on its colours or theme
  switches won't repaint it.
- Pinned mini window: `AppTask.requestWindowingLayer(PINNED)` works on the HP (logcat shows
  `windowingLayer = 2`, `isPinned=true`); only from a focused freeform task.
