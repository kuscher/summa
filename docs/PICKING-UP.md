# Picking up Summa

State and next steps, for whoever continues (human or Claude). Keep this current at every milestone.

## Where things are (v0.1)
- Engine: complete core; 324-case golden corpus passes. Performance: ~55 ms for a 1,000-line sheet on the VM.
- App: editor, answer rail, toolbar + display pill, sidebar library (pin/folders/search/trash),
  settings, themes, import/export, shortcuts. Tested on the HP (1383×810 window).
